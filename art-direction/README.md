# 摩尔庄园 · 美术画册

本目录是“图片方案 → 单体资产 → 3D 场景组装”流程的图片阶段。它与当前可漫游游戏和实机图集分别发布。

最新画风调整为清爽、圆润、简洁的卡通方向，已先更新浆果丛林主场景。`style-study.html` 提供新版与上一版对比，`styles/clean-cartoon-v2.json` 记录造型、色彩、光影要求及生成提示词。其他图稿尚未按此方向重做；本次也未更新游戏中的 3D 场景。

本批次范围为项目现有目录中的 **12 个主地区、31 个子地点、3 个浆果丛林单体参考**。这不是全部历史地图；完整候选清单见 `docs/classic-map-inventory.md`。场景图由 AI 生成，尚未与原版整图逐项核对，不应称为一比一复刻。生成图片也不代表已完成模型、碰撞、灯光、粒子或场景导入。

`catalog.json` 保存每张图片的名称、地区、提示词、生成状态及独立的 `modelStatus`。图稿原始 PNG 保存在 `images/`，不经过裁切或二次压缩。古树、浆果灌木、苔藓岩石提供透明背景单体输入；这些参考仍需经过实际图生 3D、背面检查、拓扑整理、材质检查和浏览器性能验证。

## 查看和生成发布文件

```bash
python3 scripts/art_direction.py status
python3 scripts/art_direction.py render
python3 -m http.server 4180 --directory art-direction
```

打开 `http://localhost:4180` 浏览图稿。完整网站发布后，画册位于 `/art/index.html`；可切换主地区、子地点、建模参考，按地区筛选，放大原图或下载地区 ZIP。独立本地预览时，顶部的“进入当前 3D 世界”链接需要完整网站目录才能工作。

由图像工具生成新图后，用 `python3 scripts/art_direction.py record 地点ID /绝对路径/生成图.png` 登记；工具只复制原图并更新状态，不会触发任何付费模型生成。ZIP 是可重复生成的发布文件，不进入源码历史。

## 参考边界

城堡地下室图沿用了此前根据一张旧页游室内截图生成的样稿，截图中的实际地图名称仍待核对。其他图稿依照地区名称、地标说明和统一美术方向新生成；不将推测的门窗、路径、建筑位置标为原版事实。原版参考证据与模型来源见 `docs/visual-reference.md` 和 `docs/world-atlas.md`。

后续建模应拆分建筑、植被、岩石、地面、水体和道具分别制作。单张场景效果图无法提供建筑背面、真实尺度或完整几何结构；画册只表达材质、色彩、光照和环境层次的目标。
