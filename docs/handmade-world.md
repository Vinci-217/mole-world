# 三片相连的风景 · 重构记录

## 美术方向

保留摩尔庄园的红瓦、奶油色墙体、王冠入口、巨型花亭与神秘树林，以更自然的比例、表面层次和光照组织空间。借鉴《荒野大镖客》的尺度、景深层次和有来源的光照关系，不复制其资产，也不把写实灰褐色滤镜当成沉浸感。

目前三个区域共享约 200 × 220 米的可行走区域；远山与林带延伸至探索边界之外。城堡位于北侧，花亭在东侧，古树在西北。房屋是正常建筑尺寸，处于更远位置，通过真实透视呈现远近。

## 本轮发现与修正

- 屋顶底锥遮住高处瓦片：锥顶收至零半径，使搭接瓦保持可见；补足山墙。
- 材质名称未全部匹配造成屋顶白块：补齐暗瓦、织物、苔藓与玻璃映射。
- 窗面反射与亮度太平：降低日间窗光，增加玻璃粗糙度层次和夜间暖光。
- 树形像层层横杆：提高树冠起点，改为渐细的曲线分枝，分别塑造宽冠橡树、下垂柳树和窄冠白桦，增加枝端叶簇。
- 林间近树挡住入口构图：按实际相机建立净空和有限视线走廊，保留两侧包围的树林。
- 远景仅有单色山体：增加褶皱色差及沿地形生长的远处树冠。
- 草坪空、花海颜色重复：补短草、丰富植被尺度，克制黄绿色偏色，按路径和漂移花带种植。
- 喷泉导航落入水池：把抵达位置移到外缘，并检查所有十处交互点的可达性。
- 跳跃后传送 / 坐下残留速度：在切区、移动至地点和坐下时重置跳跃状态。
- 大门有外形却无法真正打开：分离双扇门和枢轴，检查 Blender 导出再导入后的闭门阻挡 / 开门通行；运行时同步碰撞与动画。

## 学习的工作流与兼容性

阅读并应用 [CloudAI-X/threejs-skills 的材质指南](https://github.com/CloudAI-X/threejs-skills/blob/0e181866f095b5f06d005133876e926515390d95/skills/threejs-materials/SKILL.md)和[灯光指南](https://github.com/CloudAI-X/threejs-skills/blob/0e181866f095b5f06d005133876e926515390d95/skills/threejs-lighting/SKILL.md)，MIT。指南面向 r186，本项目固定 r180；没有直接照搬较新版本的 SunLight、TSL 或 WebGPU API。

应用的原则包括：色彩图使用 sRGB，法线 / 粗糙度保持线性；叶片使用透明裁切以避免整株透明排序；金属、石材、花瓣和玻璃采用不同的粗糙度 / 反射关系；环境光、方向光、补光分别控制；静态阴影按需更新；实例化与真实远近几何控制成本；HDR 后处理最后统一色调映射与输出转换。

同时参考仓库已有的 [Quick_Grass 学习记录](woodland-art-direction.md)。本轮草叶、分枝和模型为本项目构建，没有导入教程里的网格。Three.js 自带 Water、Sky、HDRLoader、后处理，以及 N8AO 等开源渲染组件直接复用，不另造同类基础轮子。

## 技术与素材

- Blender：七组真实 GLB、八个可编辑工程；空腔古树采用融合根系、布尔开洞、重拓扑与有限减面，回读后无开放边和非流形边。
- Three.js：连续地形、桥梁、道路、种植布局、雨、蝴蝶、花粉、萤火和交互动画。
- 渲染：PBR、HDR/PMREM、ACES、方向光阴影、N8AO 接触阴影、采样实际阴影的光散射、限频平面水面反射、Bloom、FXAA。
- 植被：Blender 近 / 远模型；近处精细花瓣，中距简化花卉，远处低成本花冠；花草按视锥裁剪，树木保留离屏投影。
- 许可：树皮 / HDR 为 Poly Haven CC0，树叶图集为 EZ-Tree MIT；只复用照片。其余烘焙纹理由本项目 Blender 材质生成，原版音乐单独标记权利来源。
