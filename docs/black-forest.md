# 黑森林 · Three.js 场景

入口 `black-forest.html`；页顶可切换神秘花海。两个独立场景通过链接互通。

本轮以自然比例、树冠层次、地表材质和冷暖光为重点重做。橡树、白蜡树和幼树使用 EZ-Tree 分枝骨架，并在 Blender 中调整树干弯曲、根部过渡和 UV；每种有匹配的远近模型。古树之心是 Blender 制作的连续树干，带融合根系与真实树洞。溪石也在 Blender 中制作。详细来源和许可见 `public/assets/woodland/SOURCE.md`。

地表使用原创建模材质烘焙的泥土颜色与法线，叠加路径色块、成簇弯曲细草、落叶、碎石和倒木。蘑菇以自然尺寸为主，保留少量奇幻光点。桥、遗迹、蕨类、灯具和溪流保留程序几何，并调整比例与材质。

渲染使用森林 HDR / PMREM、N8AO、ACES Filmic、克制 Bloom 和 FXAA。可见天空使用大气散射；体积光沿场景深度射线采样真实树木阴影，半分辨率运行。低位雾为连续高度积分，不使用横向半透明平面。默认林间斜阳，也可选月夜、林雾或细雨。

`forest-terrain.ts` 同时提供渲染布局、路线和步行碰撞数据。溪流需经石桥通行；树干、树洞实体与遗迹柱体有阻挡。四处导览点均可步行抵达。WASD / 方向键行走、拖动看四周、Shift 加速、Esc 退出；手机使用方向按钮。

林间音景为 Web Audio 合成风声、虫鸣和轻和弦；花海继续使用原版 BGM_131。实机截图由 `scripts/capture_forest_views.mjs` 直接保存，未作图像加工。公开学习案例和实现取舍见 `docs/woodland-art-direction.md`。当前为浏览器场景原型，未达到 3A 成品画质。
