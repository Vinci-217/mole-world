# 黑森林 · Three.js 场景

入口 `black-forest.html`，由页顶切换神秘花海。两个独立 3D 场景通过链接互通，并非无加载接缝的同一张网格地图。

以经典摩尔庄园的森林幻想为氛围参考，布局与地标是本项目改编。主景树干、扭曲根系与枝干为渐细曲线管面；古树之心由三株树干与树拱围成，可走入内部。石桥、遗迹拱顶、灯具、蘑菇和地形也用代码构建。透明裁切的树叶和远近林木复用已许可并在 Blender 整理过的 BabylonJS Assets，细节见 `public/assets/black-forest/credits.html`。

渲染复用花海的 HDR / PMREM、N8AO、适量 Bloom、Neutral 色调映射与 FXAA。月光定向阴影、低强度天空补光、桥边暖灯和蘑菇反光形成冷暖层次。独立效果包括起伏溪流法线、风中树叶、带闪烁与漂移的萤火/浮尘、低位林雾、林隙光束和细雨。月夜、林雾、细雨有独立照明及雾参数。

`forest-terrain.ts` 同时提供渲染布局、路线和步行碰撞数据。溪流必须经真实石桥通行，桥面高度与碰撞一致；树干和遗迹柱体有阻挡。导航可直达苔桥、蘑菇谷、树洞和西侧林隙，也可全程步行。WASD / 方向键移动，拖动看四周，Shift 加速，Esc 退出；手机方向按钮可行走。

林间音景使用 Web Audio 合成风声、虫鸣和轻和弦，须点击开启，并非原版黑森林 BGM。神秘花海继续使用其存档配置对应的原版 BGM_131。

验证：路径实际 CatmullRom 曲线采样、地标步行可达性、跨河防穿越、桥面高度；浏览器检查真实资产加载、漫游、氛围、声音、页面切换与手机操作。`scripts/capture_forest_views.mjs` 直接保存生产页面的 WebGL 帧，不使用参考图代替实机。性能与最终效果取决于 GPU；没有宣称达到 3A 成品画质。
