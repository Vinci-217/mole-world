# 连续世界实现与范围

本轮把单区域替换式加载改为一个持久 Three.js 场景。12 个户外地区使用 `world-atlas.ts` 中的米制坐标：城堡 (0,0)、商店街 (-180,0)、教堂 (180,0)、牧场 (0,180)、雪山 (0,-180) 等。它们通过 16 条实际道路连接。共享地表范围为 1080 × 820 米；区域建筑、树木、地形不随快速前往而销毁。

第一人称为默认入口。WASD 行走、Shift 快走，M 打开世界地图；主操作设置步行导航，引导线和可暂停的沿路漫游经过同一套碰撞检查。快速前往仅改变玩家坐标。Esc 切换鸟瞰，再进入第一人称会保留玩家位置。小地图使用全世界坐标，天气粒子和太阳阴影跟随玩家。远处植被和局部灯光会裁剪，区域仍然驻留。

## 仍未完成

注册的 31 个子地点中，8 个新增户外初版、23 个仍未搭建。城堡大厅/书房/地下、商店室内、教堂内、警署、向导社、救治室、农场屋内、草舍、猎人小屋室内、学院课堂/教导处、骑士基地等尚未完成。原作 313 个有名编号的候选清单仍保留，年代、活动图和其他地区还需核对。

画质仍低于用户要求的 3A 标准。当前工作解决连续空间、可达性和一批户外内容，不能以此宣称完整世界或美术验收通过。云端 SwiftShader 测试只能验证浏览器功能，不能作为用户显卡性能数据。

## 本轮验证

`npm run build` 通过。11 项 Chromium 集成测试全部通过：12 区驻留、19 条目的地路线的 0.25 米间隔碰撞采样、越过旧 46 米边界、全区快速前往及远处天气、第一人称/鸟瞰位置保留、夜景和音乐、子地点快速前往、自动漫游接管、手机地图及山顶与实际地形网格的离地高度。5 项 Python 资产管线测试通过（模拟 API，不收费）。高画质离线实机截图另行检查，功能通过不构成美术验收。
