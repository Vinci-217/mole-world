# 世界制作与画面验收

最终运行方式：浏览器直接打开。用户目标为经典页游地标、完整世界和尽可能接近 3A 的画面。当前版本只是向该目标推进的原型，不接受以地图数量或测试通过替代美术验收。

## 当前状态

- 12 个导览地区具备独立的户外场景，逐区加载、相机、天气与时间保留已验证；通过世界地图切换，尚未实现无缝跨区。
- 城堡使用 Blender GLB；树林使用真实树木 GLB，其他新地区的主体仍是程序网格初版。
- 原版室内、独立子地图、事件地图和历史版本变体未完成。制作范围以世界图谱及逐条地图清单持续核对，不将 12 个导览地区称为完整世界。
- 环境管线包含前向 PBR、方向光阴影、GTAO 接触阴影、多重采样、辉光、昼夜、天气、粒子和合成音乐。
- 真实 Tripo 任务仍未执行：运行环境没有安全绑定 `TRIPO_API_KEY`。已授权使用付费生成，但该凭据不能进入前端、源码或普通配置文件。

## 地图完成条件

一个地区只有在以下条件全部通过后才可标为完成：

1. 核对具体年代的实际地图参考，确认地标轮廓、配色和相对位置；记录推测及取舍。
2. 外观、室内和该地区所属独立子地图均有实际可进入的场景；删除占位物。
3. 建筑与道具采用经过检查的精细资产，补齐门窗、屋瓦、磨损、地表过渡和与环境的接触关系。
4. 地形、植物、道路、水体、灯光及粒子形成统一美术风格；消除漂浮、穿插和无来源的光或烟。
5. 白昼、黄昏、夜间和各类天气均检查实机截图，并能第一人称漫游。
6. 场景切换及返回可用，内存会释放；普通网络中断有可理解的错误反馈。

## 画质继续迭代的重点

1. 优先精修一个可验收的标杆区域：城堡正门、前庭和入口石桥。补充更可靠的原作构图参考，提升表面、植被密度及近景道具质量。
2. 将新地区的程序建筑替换为细化 GLB，先完成淘淘乐街、农场和雪山的主地标；统一比例和材质。
3. 加入经过优化的岩石、灌木和地表 PBR 资产，改善大面积单一草坪及模型与地面的过渡。
4. 精修摩尔与拉姆的形体和动画，避免简单球体组合与环境精度脱节。
5. 依据真实硬件测量调整 LOD、阴影范围和可见性。高画质在约 1080p 的目标设备上争取稳定 30 fps，流畅档争取 60 fps；尚未验收。

当前云环境没有独立显卡。Chromium 的 SwiftShader 测试能够检查渲染、资源和控制功能，不能据此声称消费级显卡上的帧率达标，也不能证明达到 3A 画面。
