## 代码中的状态

注册表位于 [src/world-atlas.ts](../src/world-atlas.ts)。`courtyard-prototype` 表示现有城堡前庭重构；`under-construction` 表示其他地区仍在制作。独立地区即使已有可漫游的户外初版，也不代表官方地图已还原，或附属室内、任务及小游戏已经完成。所有 `sublocations` 均明确标为 `not-built`。

`evidence: name-listed` 仅表示相关地区名称可以在上述名表核对；`version-uncertain` 用于本轮证据不足的黑森林。摩尔拉雅雪山是对山脚、滑冰场和山顶的导览总称；游乐场合并了东西两个分图。

## 连接世界的坐标约定

每个地区的 `worldPosition` 是平移原点，单位采用米，Y 向上，X 向东，Z 向南。城堡沿用现有原点；相邻区域原点间距 180 米，为后续道路和地区加载保留空间。地区内模型继续使用局部坐标，`regionWorldPosition(id, local)` 提供平移换算，不擅自改变原模型朝向。

图谱坐标使用百分比：`mapX = 50 + worldX / 12`，`mapY = 50 + worldZ / 9`。这使图谱标记和地区平移共享同一套数据。该转换用于项目导航；地理方位与距离均未经原版地图核实。现有单个地区的切换与独立展示，也不应被称为已经实现无缝相连的完整世界。

建模遵循现有原创网格与程序材质流程。网页截图用于观察，不随站点打包；注册表不包含提取的游戏资产、远程游戏资源地址或任何密钥。
